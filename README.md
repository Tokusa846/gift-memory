# Gift Memory
Gift Memory(仮名):
プレゼントの「もらった・あげた」を記録し、相手ごとの情報とあわせて管理できるWebアプリです。

「誰から何をもらったか思い出せない」
「以前この人に何をプレゼントしたか忘れてしまった」
「誕生日やお返しを忘れたくない」

といった、プレゼントにまつわる情報管理を手軽に行うことを目的として制作しました。

人物ごとに誕生日や好みなどの情報を登録し、プレゼントの履歴と紐づけて管理できます。
また、誕生日やお返しが必要なプレゼントをリマインダーとして表示し、週間カレンダーから直近のイベントを確認できます。
